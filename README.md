# CubeShooter

CubeShooter is a rail shooter where you control a cube shooting cubes at cubes.
It is build with ViennaVulkanEngine and ViennaPhysicsEngine as part of a Gaming Technologies course at the University of Vienna.
It implements A* algorithm for enemy behavior, different gravitational forces for different objects as well as a multi-part boss battle.

### Controls

| Key                | Description                                                          |
|--------------------|--------------------------------------------------------------------- |
| <kbd>T</kbd>       | Move up                                                              |
| <kbd>F</kbd>       | Move left                                                            |
| <kbd>H</kbd>       | Move right                                                           |
| <kbd>G</kbd>       | Move down                                                            |
| <kbd>L</kbd>       | Shoot                                                                |
